# 자유 밭과 삽 도구 설계

## 목표

- 새 게임과 기존 세이브에서 자동으로 제공되던 6×4 기본 밭을 제거한다.
- 모든 밭은 호미로 지면 타일을 갈아 만들며 같은 0.9×0.9 월드 크기를 사용한다.
- 삽을 선택하고 빈 밭과 상호작용하면 그 밭을 다시 잔디로 되돌린다.
- 작물이 심겼거나 물을 준 밭, 수확 가능한 밭은 실수로 철거하지 못하게 한다.

## 데이터와 마이그레이션

`FarmPlotData.freeform`이 `true`인 항목만 플레이어가 만든 밭으로 취급한다. 세이브 정규화 시 이전 버전이 강제로 만들었던 `freeform == false` 항목을 제거하고, 자유 배치 밭은 위치와 작물 상태를 그대로 보존한다. 새 게임은 빈 `farmPlots` 목록으로 시작한다. 세이브 버전을 올려 이 변경을 명시한다.

## 상호작용

호미는 기존처럼 `Space` 또는 빈 지면 상호작용으로 밭을 만든다. 삽은 가방의 독립 도구로 제공하며, 가까운 밭에서 `E`를 누르면 동작한다. `Tilled` 상태인 자유 배치 밭만 제거할 수 있다. 작물이 있는 밭에서는 안내 메시지만 표시한다. 밭 제거 직후 저장하고 화면 오브젝트 목록을 다시 동기화한다.

## 표현과 UI

밭 생성은 `FreeformFarmField` 한 곳에서 담당하며 크기를 0.9×0.9로 고정한다. 시작 월드를 만들 때 별도의 1.1×1.1 밭을 생성하지 않는다. 가방 도구 줄은 여섯 칸으로 재배치하고 삽 버튼을 추가한다. 손에 든 삽은 작은 픽셀 스프라이트를 절차적으로 생성해 다른 도구와 같은 방식으로 표시한다.

## 검증

- 새 게임에 기본 밭이 없는지 에디터 테스트로 확인한다.
- 구버전 기본 밭은 제거되고 자유 배치 밭은 보존되는지 확인한다.
- PlayMode에서 밭을 만든 뒤 크기 0.9×0.9를 확인하고, 삽으로 제거되는지 확인한다.
- 작물이 심긴 밭은 삽으로 제거되지 않는지 확인한다.
- 메인 씬 스모크 테스트와 WebGL 빌드를 다시 실행한다.
