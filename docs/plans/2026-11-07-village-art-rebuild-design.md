# C 마을 아트 재구축

## 목표

프로토타입의 단색 사각형을 실제 게임 오브젝트로 교체하고, 선택한 C 마을 배치가 화면에서 바로 읽히게 한다.

## 적용 범위

- 농장 집, 시청, 잡화점, 씨앗·사료 상점, 서쪽 집, 동쪽 집은 서로 다른 전용 이미지로 구성한다.
- 광장 중앙에는 원형 포장, 벤치, 가로등, 화단, 퀘스트 게시판을 한 묶음으로 배치한다.
- 연못과 계절 색이 적용되는 나무를 실제 이미지로 교체한다.
- 농장에 닭장과 닭을 실제 이미지로 표시한다.
- 건물과 나무의 충돌 영역은 출입구와 통행로를 막지 않는 하단부에 둔다.

## 캐릭터 보정

기존 캐릭터 시트는 192x256 균등 격자가 아니었다. 실제 사용 영역은 160x208이며 행과 열 간격도 서로 다르다. 프레임별 측정 좌표를 사용해 바로 아래 행의 머리카락이 검은 선처럼 끼어들지 않게 하고, 모든 방향의 발 위치를 같은 피벗에 맞춘다.

## 검증 기준

- 모든 주요 월드 오브젝트는 1x1 임시 텍스처가 아닌 전용 이미지를 사용한다.
- 농장 집, 서쪽 집, 동쪽 집은 서로 다른 텍스처를 사용한다.
- 플레이어 정면 프레임은 측정한 160x224 영역을 사용한다.
- WebGL에서 농장, 실내, 광장, NPC 대화 화면을 캡처해 실제 배치와 겹침을 확인한다.
