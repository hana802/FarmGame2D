# 의뢰 게시판 3일 갱신과 UI 안전 영역 설계

## 목표

게시판 제목, 안내 문구, 의뢰 버튼과 닫기 버튼이 그림 테두리나 장식 칸을 침범하지 않게 정렬한다. 게시판에는 다섯 종류 중 세 개의 의뢰만 표시하며 게임 시간 3일마다 목록을 갱신한다.

## 갱신 규칙

- 1~3일, 4~6일과 같이 3일 단위의 게시판 주기를 사용한다.
- 월드 시드와 현재 주기를 조합해 다섯 종류 중 서로 다른 세 의뢰를 결정한다.
- 같은 주기 안에서는 저장·불러오기 후에도 같은 목록이 나온다.
- 진행 중인 의뢰가 새 목록에 없다면 세 번째 칸에 유지해 중간에 사라지지 않게 한다.
- UI에 다음 갱신까지 남은 게임 날짜를 표시한다.

## UI 레이아웃

- 인벤토리와 같은 820×550 창 프레임을 사용한다.
- 제목은 왼쪽 장식 칸을 피한 오른쪽 제목 영역에 배치한다.
- 상태 문구와 갱신 안내는 제목 아래의 본문 안전 영역에 배치한다.
- 세 개의 의뢰 버튼은 일정한 62픽셀 간격으로 배치한다.
- 닫기 버튼은 하단의 두 장식 버튼 칸을 덮는 하나의 정상 버튼으로 배치한다.

## 검증

- 1일과 3일 목록은 같고 4일 목록은 달라지는지 확인한다.
- 갱신 후에도 진행 중인 의뢰가 포함되는지 확인한다.
- 제목, 상태, 갱신 문구, 세 번째 의뢰 버튼과 닫기 버튼이 서로 겹치지 않는지 확인한다.
