# NPC 상호작용·호감도 설계

## 목표

플레이어가 NPC 앞에서 `E`를 눌렀을 때 단순 대사 대신 상호작용 창을 열고, 대화하거나 인벤토리의 물건을 선물해 관계를 쌓을 수 있게 한다.

## 플레이 흐름

1. NPC 근처에서 `E`를 누르면 NPC 이름과 현재 호감도(0~100, 하트 5칸)가 표시된다.
2. `대화하기`를 고르면 기존 NPC별 순환 대사를 재사용한다.
3. `선물하기`를 고르면 보유 중인 수확물, 축산물, 물고기, 광물만 스크롤 목록에 표시된다.
4. NPC별 선호 선물은 호감도 20, 좋아하는 선물은 10, 일반 선물은 4가 오른다.
5. 같은 NPC에게는 하루 한 번만 선물할 수 있으며, 제한에 걸린 시도는 아이템을 소모하지 않는다.

## 저장

NPC 식별자, 누적 호감도, 마지막 선물 날짜를 저장 데이터 버전 7에 포함한다. 이전 저장은 정규화 단계에서 빈 호감도 목록을 자동 생성한다. 선물 성공 직후 로컬 및 연결된 기기 저장 동기화를 요청한다.

## UI 원칙

- 게임을 가리지 않도록 1600×900 기준 중앙 패널을 사용한다.
- 한글 전용 폰트를 사용하고 기존 초상화 대화창을 그대로 이어서 보여준다.
- 창이 열려 있는 동안 플레이어 이동과 추가 상호작용을 막는다.
- NPC는 선택 중 자리를 떠나지 않도록 잠시 멈춘다.
