# 보행 가능한 광장과 의뢰 게시판 분리 설계

## 목표

광장 원형 돌바닥은 플레이어가 자유롭게 올라가 걸을 수 있게 하고, 게시판 본체만 통과할 수 없는 상호작용 구조물로 분리한다. 게시판 앞에서 상호작용하면 의뢰 선택 창을 열고, 수락한 의뢰는 휴대폰에서 추적하며 목표 달성 시 보상과 저장 처리를 수행한다.

## 화면과 충돌 구조

- 광장 전체 그림은 길보다 위, 플레이어보다 아래인 배경 정렬 순서 `2`로 표시한다.
- 원본 이미지의 게시판 영역만 별도 스프라이트로 잘라 건물 깊이 순서를 적용한다.
- 광장 바닥 자체에는 충돌체를 두지 않는다.
- 좁은 광장 통로를 막지 않도록 벤치·화단·화분은 보행 가능한 장식으로 처리한다.
- 게시판 본체에만 고체 충돌체를 유지한다.
- 게시판 앞의 상호작용 범위는 아래쪽 통로까지 넓게 이어지는 트리거로 두어 이동을 막지 않는다.
- `E` 상호작용 안내는 플레이어가 범위 안에 머무는 동안 계속 표시한다.

## 의뢰 흐름

게시판 상호작용 시 다섯 가지 초반 의뢰 목록을 표시한다. 진행 중인 의뢰가 없을 때만 하나를 선택할 수 있고, 수락 후 게시판 창은 닫힌다. 휴대폰 UI에서 현재 목표와 진행도를 확인하며, 수확·달걀·잡초·낚시·채광 행동이 해당 목표를 갱신한다. 완료 시 돈 보상을 한 번만 지급하고 자동 저장한다.

## 검증

- 광장 바닥 렌더러가 배경 순서인지 확인한다.
- 광장 루트에 이동 차단 충돌체가 없는지 확인한다.
- 게시판 전용 스프라이트와 고체 충돌체가 존재하는지 확인한다.
- 상호작용 영역이 트리거인지 확인한다.
- 장식물 충돌체가 생성되지 않고 게시판 접근 통로가 열려 있는지 확인한다.
- 게시판 앞에 1초 이상 머물러도 `E` 안내가 유지되는지 확인한다.
- 게시판을 열었을 때 다섯 개 의뢰가 제공되는지 확인한다.
