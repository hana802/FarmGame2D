# 캐릭터·UI 아트 연결 설계

## 목적

기능 검증용 1×1 단색 스프라이트와 기본 `GUI.Box`를 제거하고, 이미 확정한 캐릭터·NPC·UI 시안을 실제 플레이 화면에 연결한다. 농사, 저장, 퀘스트 등 게임 규칙은 변경하지 않는다.

## 구현 구조

- `GameArtCatalog`가 `Resources/Art`의 플레이어·NPC 스프라이트 시트와 UI 아틀라스를 불러온다.
- 플레이어 시트는 8열×4행으로 나누며, 남성형은 앞쪽 4열, 여성형은 뒤쪽 4열을 사용한다.
- 이동 방향과 시간에 따라 4방향·4프레임 스프라이트를 선택한다.
- 안내자 하람, 주민 순자, 주민 도윤은 NPC 시트의 서로 다른 행을 사용한다.
- `FarmGuiSkin`은 UI 아틀라스의 대화창, 창 패널, 배너와 버튼 영역을 화면 크기에 맞춰 그린다.
- `PrototypeHud`의 상태·퀘스트·도구·대화·캐릭터 선택·휴대폰·상점 기능은 그대로 유지하고 배경과 글자색만 새 스킨에 맞춘다.

## 검증 기준

- 플레이어와 NPC의 텍스처 너비가 1픽셀보다 커야 한다.
- HUD가 UI 아틀라스를 성공적으로 불러와야 한다.
- Main 씬 PlayMode 테스트와 기존 EditMode 테스트가 모두 통과해야 한다.
- Windows 실행 파일이 성공적으로 빌드되고 시작 로그에 런타임 예외가 없어야 한다.
