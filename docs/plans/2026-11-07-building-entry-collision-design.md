# 건물 출입과 충돌 보정

## 결정

건물에 닿자마자 자동 입장시키지 않고, 현관 앞에서 `E` 안내를 표시한 뒤 사용자가 선택해 들어가는 방식을 사용한다.

## 구조

- 건물 하단의 좌우 외벽과 닫힌 문에 각각 고정 충돌체를 둔다.
- 문 앞에는 별도의 상호작용 트리거를 둔다.
- 농장 집은 `E: 집에 들어가기`로 실제 실내에 이동한다.
- 아직 내부가 없는 시청·잡화점·주택은 건물별 입장 안내 후 준비 중이거나 잠겨 있다는 메시지를 표시한다.
- 씨앗·사료 상점은 문 앞에서 기존 상점 화면을 연다.

## 검증

플레이 모드 테스트에서 농장 집의 좌우 벽과 문 충돌체가 고정 충돌체인지, 문 트리거와 마을 건물 안내가 존재하는지 확인한다. WebGL 캡처로 문 앞 정지, 안내 표시, 실내 이동을 함께 확인한다.
