# NPC 대화 UI 재설계

## 목표

NPC 대화에서 초상화, 이름과 본문이 서로 겹치지 않게 하고 게임 화면을 가리는 면적을 줄인다. 기존 농장풍 나무·종이 UI와 NPC 초상화는 유지한다.

## 선택한 구성

- 대화창은 화면 하단 중앙의 1056×158 카드로 표시한다.
- 왼쪽에는 116×116 초상화 전용 영역을 둔다.
- 이름은 원본 UI의 상단 이름표 장식 안에 가운데 정렬한다.
- 본문은 초상화 오른쪽의 독립된 영역에서 최대 여러 줄로 줄바꿈하고 영역 밖 글자는 잘라낸다.
- 대화창의 아래쪽 끝은 단축 바보다 위에 두어 두 UI가 겹치지 않게 한다.

## 구현과 검증

`HudLayout.CalculateDialogueLayout`이 대화 카드의 모든 영역을 계산하고 `PrototypeHud`는 계산 결과만 사용해 그린다. EditMode 테스트에서 초상화와 본문, 이름과 본문, 대화 카드와 단축 바가 겹치지 않는지 확인한다. WebGL 빌드에서는 실제 NPC 대화를 열어 글자 위치와 줄바꿈을 시각적으로 확인한다.
