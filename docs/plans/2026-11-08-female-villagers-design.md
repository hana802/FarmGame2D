# 여성 주민 추가 설계

## 목표

마을에 여성 주민 두 명을 추가해 성별과 직업 구성을 넓힌다. 두 주민은 기존 NPC와 동일하게 길망을 따라 이동하고, 주민끼리 대화하며, 플레이어에게 말을 걸 수 있어야 한다. 대화창에는 기존 민서·태오 초상화와 같은 완성도의 전용 픽셀 일러스트를 표시한다.

## 구성

- 제빵사 유나: 녹색 두건과 앞치마를 착용한 친근한 주민. 광장 서쪽과 상점 주변을 중심으로 이동하며 계절 작물, 밀, 빵, 마을 사람들의 안부에 관한 대사를 사용한다.
- 목장 관리인 소라: 붉은 리본의 묶음머리와 목장 작업복을 착용한 활기찬 주민. 광장 동쪽과 동물 상점 주변을 중심으로 이동하며 동물 돌봄, 번식, 휴식에 관한 대사를 사용한다.

## 구현 방식

새 NPC도 기존 `DialogueInteractable`, `WanderingMover`, `NpcSocialAgent`를 그대로 사용한다. 초상화 ID 6과 7을 `GameArtCatalog`에 등록하고, 월드 캐릭터는 기존 스프라이트 자산을 재사용한다. 공통 스프라이트 적용 코드는 한 경로로 합쳐 충돌체 크기와 깊이 정렬이 동일하게 유지되도록 한다.

## 검증

에디터 테스트에서 두 초상화가 전용 이름과 1024px 이상의 해상도를 갖는지 확인한다. 플레이 모드 스모크 테스트에서 두 NPC의 생성, 이동 컴포넌트, 사회적 대화 컴포넌트, 서로 다른 전용 초상화를 확인한다.
