# FarmGame2D 플레이 가능 통합 버전 설계

## 목표

첫 통합 버전은 임시 그래픽을 사용하더라도 새 게임부터 저장까지 하나의 농장 생활 순환을 직접 플레이할 수 있어야 한다. 플레이어는 캐릭터를 선택하고 이동하여 밭을 갈고, 밀을 심고 물을 주며, 취침 후 성장한 밀을 수확한다. 상점에서 씨앗과 사료를 사고, 닭에게 먹이를 주고 달걀을 모으며, 수확물을 판매해 다시 농장 활동에 사용한다.

## 포함 범위

- 저장된 `Main` 씬과 런타임 월드 생성
- 남성형·여성형 선택, 4방향 이동, 충돌과 상호작용
- 32 PPU 기준 픽셀 퍼펙트 카메라
- C안 중심가형 마을과 농장 프로토타입
- 갈기, 파종, 물 주기, 날짜 성장, 밀 수확
- 씨앗·밀·사료·달걀 인벤토리와 3개 도구 슬롯
- 상점 구매, 판매 상자와 돈
- 닭 먹이와 달걀 생산
- 취침, 다음 날 처리와 자동 저장
- 휴대폰 수동 저장과 불러오기
- 첫 밀 수확 퀘스트와 초기 도전 과제
- 안내자·주민 대화와 조작 안내
- 28일 단위 계절 전환과 시드 기반 마을 장식 배치

## 구조

`GameSession`이 현재 저장 데이터와 도메인 규칙을 소유한다. 플레이어, 밭, 닭, 상점과 UI는 `GameSession`의 공개 동작을 호출하고 상태 변경 알림을 받아 화면을 갱신한다. 저장은 직렬화 가능한 `GameSaveData`만 JSON으로 기록하며 Unity 오브젝트 참조는 저장하지 않는다.

`PrototypeWorldBuilder`는 저장된 월드 시드를 사용해 C안의 중심축과 필수 건물 위치를 보장하고 나무·연못 주변 장식을 변화시킨다. 계절이 변해도 배치는 다시 생성하지 않고 바닥, 나무와 물의 색만 변경한다.

## 프로토타입 한계

콘셉트 이미지는 최종 스프라이트 시트가 아니므로 이번 버전은 단색 픽셀 도형과 런타임 타일을 사용한다. 닭에게 먹이를 주지 않으면 현재는 달걀만 생산하지 않으며 친밀도 하락이나 질병은 적용하지 않는다. 이 규칙은 추후 기획 결정 후 교체한다.
