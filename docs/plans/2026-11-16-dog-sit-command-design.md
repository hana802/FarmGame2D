# 강아지 앉아 / 따라와 명령

플레이 중 `G`를 누르면 강아지가 현재 위치에 앉고, 다시 누르면 플레이어를 따라온다. 현재 명령은 화면 왼쪽 아래에 표시한다. 앉아 있는 동안 쓰다듬기는 가능하지만 강아지가 플레이어 주위를 뛰어다니지 않는다.

`dogSitting`과 앉은 위치를 저장 데이터에 넣어 저장/불러오기 및 브라우저 간 동기화 시 복원한다. 기존 저장에는 필드가 없으므로 기본값인 따라오기 상태로 시작한다.

NPC 등 다른 상호작용 대상과 강아지가 동시에 `E` 범위 안에 있을 때는 다른 대상을 먼저 선택한다. 강아지만 가까이 있으면 기존처럼 `E`로 쓰다듬는다.

검증: 강아지 앉기 중 플레이어 이동에도 강아지가 제자리에 있는지, 따라오기 재개 시 이동하는지, 상태와 좌표가 저장 직렬화 뒤 유지되는지 확인한다.
