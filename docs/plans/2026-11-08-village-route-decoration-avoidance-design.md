# 광장 장식물 회피 경로 설계

## 원인

마을 광장의 벤치·화분·가로등은 게시판 접근로를 막지 않도록 충돌체가 없다. 기존 NPC 길망은 광장 아래 좌우 지점에서 위쪽 중앙 지점으로 곧바로 연결되어, 이 대각선 구간이 장식물 그림을 통과한다. NPC가 장식물 위에서 대기하거나 게시판 충돌체 가장자리에서 같은 이동을 반복하면 끼인 것처럼 보인다.

## 수정

장식물 충돌체는 다시 추가하지 않는다. 대신 광장 좌우 바깥쪽에 우회 노드를 하나씩 추가하고, 아래쪽 길과 위쪽 길 사이의 연결은 반드시 이 노드를 통하도록 변경한다. 기존 NPC의 집 노드 번호는 유지해 저장 및 이동 설정에 영향을 주지 않는다.

## 검증

에디터 테스트에서 광장 아래 좌우 노드에서 위쪽 중앙 노드로 이동할 때 직접 연결되지 않고, 각각 x 좌표 -4.2 이하와 4.2 이상의 우회 노드를 첫 단계로 선택하는지 확인한다.
