# 연애 후보 NPC 대화 초상화 디자인

## 적용 대상

- 어부 민서: 바다색 재킷, 조개 머리핀, 옆머리 땋기와 주근깨로 밝고 활동적인 어부의 인상을 강조한다.
- 원예가 태오: 웨이브 진 갈색 머리, 올리브색 작업복, 꽃 장식과 정원 도구로 다정하고 차분한 원예가의 인상을 강조한다.

## 표현 원칙

- 기존 월드 캐릭터는 유지하고, NPC를 클릭했을 때 표시되는 대화창에 전용 초상화를 사용한다.
- 선명한 외곽선과 제한된 색상 팔레트를 사용하는 고해상도 도트 스타일을 유지한다.
- 얼굴 표정과 직업 소품을 크게 보여 작은 대화창에서도 캐릭터의 개성이 바로 읽히게 한다.
- 두 NPC는 서로 다른 전용 리소스와 초상화 ID를 사용한다.

## 리소스 연결

- 민서: `Art/NPCs/romance_minseo_portrait_v1`, 초상화 ID `4`
- 태오: `Art/NPCs/romance_taeo_portrait_v1`, 초상화 ID `5`
