# 가방·지형·실내 확장

## 플레이 흐름

- 화면 상단에는 계절, 날짜, 시간, 돈과 퀘스트만 표시한다.
- 아이템 수량은 `I` 또는 `B`로 가방을 열었을 때만 확인한다.
- 호미, 밀 씨앗, 물뿌리개는 가방 버튼으로 선택해 손에 든다. 기존 숫자키 즉시 선택은 제거한다.
- 가방, 휴대폰, 상점 중 하나만 열 수 있으며 창이 열린 동안 플레이어는 움직이거나 상호작용하지 않는다.

## 월드 표현

- 단색 잔디는 계절 색조가 적용되는 잔디 텍스처로 교체한다.
- 마을과 농장 연결 길은 밝은 돌길 텍스처를 사용한다.
- 농장 집 내부에 침대, 러그, 원형 탁자와 의자, 수납장을 배치한다.

## 잡초

- 월드의 고정 위치에 잡초를 배치한다.
- 가까이에서 `E`를 누르면 잡초가 사라지고 가방에 잡초 1개가 들어간다.
- 뽑은 잡초 번호를 저장 데이터에 기록해 저장·불러오기 후 다시 나타나지 않게 한다.

## 검증

- 타일맵이 1×1 임시 텍스처가 아닌 실제 잔디와 돌길 이미지를 사용하는지 확인한다.
- 집 안의 네 가지 소품과 잡초가 실제 이미지로 생성되는지 확인한다.
- 잡초 아이템 수량과 가방 상태를 자동 테스트하고 WebGL 화면에서 HUD 여백, 실내, 가방을 확인한다.
