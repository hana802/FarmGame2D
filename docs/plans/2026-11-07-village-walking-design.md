# 마을 이동 구현 설계

## 목표

Unity에서 `Main` 씬을 실행하면 중심가형 마을, 플레이어와 카메라가 자동으로 준비되고 플레이어가 WASD 또는 방향키로 마을과 농장을 돌아다닐 수 있어야 한다. 건물, 연못, 나무와 월드 경계는 통과할 수 없으며 대각선 이동 속도는 직선 이동 속도와 같아야 한다.

## 구조

- `FarmGameBootstrap`은 씬에 필요한 `GameSession`, 런타임 월드, 플레이어, 카메라와 HUD를 한 번만 생성한다.
- `PrototypeWorldBuilder`는 선택된 C안 중심가형 배치를 타일맵과 충돌 오브젝트로 구성한다. 랜덤 나무는 저장된 월드 시드로 결정하지만 시작 지점, 도로, 연못과 건물 주변은 피한다.
- `PrototypePlayerController`는 입력 수집과 물리 이동을 담당한다. 입력 벡터를 최대 길이 1로 제한하고 `Rigidbody2D.MovePosition`을 고정 프레임에서 호출한다.
- `PixelCameraFollow`는 플레이어 좌표를 32 PPU 격자에 맞춰 따라가며 기존 카메라 구성 요소가 있으면 재사용한다.
- `PrototypeHud`는 캐릭터 선택, 이동·상호작용 조작과 가까운 대상 안내를 표시한다.

## 실행과 검증

`Assets/Scenes/Main.unity`를 빌드 목록의 첫 씬으로 등록한다. 런타임과 테스트 어셈블리 컴파일, Main 씬 생성 여부, 빌드 설정 등록을 확인한다. 플레이 모드에서는 캐릭터 선택 후 WASD·방향키 이동, 대각선 속도, 건물·연못·나무 충돌, 카메라 추적과 E 상호작용을 확인한다.
