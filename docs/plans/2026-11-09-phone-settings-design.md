# 휴대폰 설정 탭 설계

## 목표

기존 `P`키 휴대폰을 유지하면서 휴대폰 안에 `농장`과 `설정` 탭을 둔다. 농장 탭은 현재 퀘스트, 로컬 저장/불러오기, 브라우저 동기화를 그대로 제공한다. 설정 탭은 전체 음량, 즉시 저장, 저장 후 나가기를 제공한다.

## 구조

- `GameAudioSettings`가 전체 음량의 불러오기, 범위 제한, `AudioListener` 적용, `PlayerPrefs` 저장을 담당한다.
- `PrototypeHud`는 현재 휴대폰 탭과 나가기 확인 상태만 관리한다.
- `HudLayout`은 확장된 휴대폰 패널의 탭, 슬라이더, 버튼, 확인창 좌표를 제공한다.
- 나가기 버튼은 확인 단계를 거친다. 확인하면 먼저 게임을 저장한다. 데스크톱 빌드는 `Application.Quit`을 호출하고 WebGL은 브라우저 정책상 탭을 닫을 수 없으므로 저장 완료 안내를 표시한다.

## 검증

- 음량 값이 0~1 범위로 제한되는지 EditMode 테스트로 확인한다.
- 저장된 음량을 다시 읽어 `AudioListener.volume`에 적용하는지 확인한다.
- 휴대폰 레이아웃의 설정 컨트롤이 패널 안에 배치되는지 확인한다.
- 기존 EditMode/PlayMode 전체 테스트와 WebGL 빌드를 실행한다.
