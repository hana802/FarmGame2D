# FarmGame2D 2026년 11월 7일 프로젝트 기록

## 프로젝트 현황

FarmGame2D는 Unity 6.6으로 제작하는 탑다운 2D 픽셀아트 생활형 농장 RPG다. 스타듀 밸리의 생활 순환 구조를 참고하지만 캐릭터, 세계관, 그래픽과 세부 규칙은 독자적으로 설계한다.

- 로컬 프로젝트: `C:\Users\User\Desktop\sud\FarmGame2D`
- Unity 버전: `6000.6.8f1`
- GitHub 저장소: `https://github.com/hana802/FarmGame2D`
- 저장소 공개 범위: 공개
- 기본 브랜치: `main`

## 확정된 기획

- 농사와 농장 확장을 핵심 재미로 삼는다.
- 목축업을 포함하지만 첫 버전은 닭만 다룬다.
- 첫 지역은 농장과 작은 마을로 구성한다.
- 첫 버전은 PC를 대상으로 하며 키보드와 마우스로 조작한다.
- 플레이어는 남성 캐릭터와 여성 캐릭터 중에서 선택할 수 있다.
- 플레이어는 32×32 논리 셀의 탑다운 4방향 대기·걷기 스프라이트를 사용한다.
- 초반 안내자와 간단한 마을 주민 NPC를 둔다.
- 인물 초상과 이름표가 있는 대화창, 별도의 게임 안내창을 준비한다.
- 첫 작물은 밀이다.
- 게임 시간은 현실보다 20배 빠르게 흐른다.
  - 게임 1분은 현실 3초다.
  - 현실 1분은 게임 20분이다.
  - 게임 24시간은 현실 1시간 12분이다.
  - 오전 6시부터 밤 10시까지는 현실 48분이다.
- 퀘스트는 마을 광장이나 게임 내 휴대폰을 통해 제공한다.
- 농사와 생활 기록을 장기 목표로 삼는 도전 과제를 넣는다.
- 게임 내 휴대폰으로 언제든 수동 저장할 수 있다.
- 취침할 때 시스템이 한 번 자동 저장한다.
- 새 아이디어는 먼저 문서에 기록하며 명시적인 요청이 있을 때만 구현한다.

## 현재 구현된 내용

- Unity 2D 프로젝트와 공식 2D 기능 패키지
- 게임 시간 계산
  - 1일 차 오전 6시 시작
  - 날짜 증가와 자정 처리
- 화면 오른쪽 위의 초기 시간 표시
- 씬과 무관하게 시간 시스템을 생성하는 부트스트랩
- 시간 계산 EditMode 테스트 4개
- Unity용 `.gitignore`
- Git 저장소와 GitHub 원격 연결
- 플레이어 캐릭터, 안내자·주민 NPC, 대화·안내 UI 콘셉트 이미지

시간 테스트 4개는 모두 통과했고 컴파일 오류는 확인되지 않았다.

## 구현과 기획의 차이

현재 코드의 시간 속도는 현실 7초마다 게임 10분이 흐르는 초기 검증값이다. 확정된 기획은 20배속이지만, 기획 기록만 해달라는 원칙에 따라 아직 코드를 변경하지 않았다.

현재 시간 표시는 초기 검증용 `OnGUI` 방식이다. 정식 게임 화면을 만들 때 픽셀아트 UI로 교체해야 한다.

## 아직 구현하지 않은 내용

- 저장된 플레이용 씬
- 플레이어 이동, 충돌과 상호작용
- 픽셀 퍼펙트 카메라
- 농장과 작은 마을 맵
- 밀 재배와 농사 도구
- 인벤토리와 단축 슬롯
- 상점, 돈과 판매 상자
- 닭, 닭장, 먹이와 달걀 생산
- 취침과 하루 종료 처리
- 휴대폰 수동 저장과 취침 자동 저장
- 퀘스트와 도전 과제
- 정식 UI와 픽셀아트 리소스
- NPC 대화 데이터와 튜토리얼 진행 로직

콘셉트 이미지는 `Assets/Art/Concepts`에 저장했으며 아직 실제 스프라이트로 슬라이스하거나 게임 오브젝트에 연결하지 않았다.
