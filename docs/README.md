## 프로토타입 실행과 조작

Unity에서 `Assets/Scenes/Main.unity`를 열고 Play를 누른다.

- `M` / `F`: 남성형·여성형 캐릭터 선택
- `WASD` 또는 방향키: 이동
- `E`: 밭, 닭, NPC, 상점, 침대와 판매 상자 상호작용
- `1` / `2` / `3`: 호미, 밀 씨앗, 물뿌리개 선택
- `P`: 휴대폰 열기·닫기
- `F5`: 수동 저장
- `F9`: 저장 데이터 불러오기
- `F6`: 계절 전환 미리보기용 디버그 기능

밀은 땅 갈기, 씨앗 심기, 물 주기를 거쳐 물을 준 날이 두 번 지나면 수확할 수 있다. 침대에서 취침하면 다음 날 오전 6시로 이동하며 자동 저장한다.

남성형·여성형 플레이어는 4방향 걷기 애니메이션을 사용한다. 안내자와 주민은 각기 다른 NPC 외형을 사용하며, 대화·휴대폰·상점·퀘스트 UI에는 나무와 아이보리 색상의 농장 UI 스킨이 적용되어 있다.
